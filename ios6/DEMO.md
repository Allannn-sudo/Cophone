# 1–2分钟演示

演示前用真实任务完成一次冒烟检查，确认服务、模型额度和oldbili联网可用，不在正式录像时首次安装组件。不要用缓存回放代替本轮画面。

1. 镜头同时拍到 iPhone 和 Mac。Mac 打开“查看 cophone 执行画面.command”，保留任务ID和帧时间。
2. iPhone 打开 cophone 一次保留后台，长按 Home 说：**“找两个三十分钟以内的 AI Agent 入门视频，比较后推荐一个，把理由记到备忘录。”** 核对转写，点开始。
3. 立即在 Safari 打开网页，持续滚动或在搜索框输入文字。不要停用手机等待，不打开oldbili。
4. Mac 应显示真实 oldbili 独立搜索控制器：搜索词、真实列表、候选读取时的滚动，以及右侧手机端Agent每一步的动作与理由。镜头同时记录手机未跳转、键盘归用户。
5. 收到完成通知后，点击直接进入本次笔记正文，展示主题标题、两条真实视频、时长/UP主、比较理由。此处是结果核验；不要把单纯进度横幅当完成证明。
6. 时间允许可加一段 Safari 选文→整理成摘要/图片，继续浏览。Mac切到对应任务，展示真实选文、返回摘要/PNG以及保存验证，最终核对系统备忘录或照片/cophone相簿。生图额外调用千问，时长不固定。

也可提前启动“目视官”，让Mac同时显示实际采集到的应用时段和网页/视频分段。回桌面6秒后核对回顾正文。摘要/配图/目视官的数据面板与oldbili真实App画面分开标注，不能把数据面板当作第三方App投屏来宣称通过画面要求。

**通过条件：** 本轮任务ID一致、画面有新时间戳和实际App内容、用户手机持续可用、系统Notes回读成功且用户能看到结果。如果仅有进度文字或旧帧，执行画面要求尚未通过。

**现场失败：** 明确展示错误与停止原因，不把超时说成完成；模型/第三方网络可能波动，正式交付附原始演示视频比只截图更有说服力。不要在公开视频露出API Key。
